# mudl

Uma ferramenta que instala músicas no terminal.

## Como Usar

    # Adicionar uma música
    mudl -c

    # Ver todas as músicas registradas
    mudl -l

    # Atualizar o registro de uma música
    mudl -a

    # Remover o registro de uma música
    mudl -r

    # Instalar as músicas registradas
    mudl

## Instalação

### Dependências

- deno
***

Após instalar as dependências, é possível instalar a ferramenta com o gerenciador de pacotes em python de sua preferência.

Exemplo de instalação:

    uv tool install git+https://github.com/jcabral78/mudl
