# mudl

Uma ferramenta que categoriza instala músicas.

## Como Usar

    # Adicionar uma música
    mudl -c

    # Ver todas as músicas registradas
    mudl -l

    # Atualizar o registro de uma música
    mudl -a

    # Remover o registro de uma música
    mudl -r

    # Instalar as músicas registradas
    mudl

## Instalação

### Dependências

- deno
- uv
***

Após instalar as dependências rode esse comando:

    uv tool install git+https://github.com/jcabral78/mudl
